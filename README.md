# Bistro Pasta Quiz Navigator

## Быстрый запуск на macOS
1. Откройте **Terminal**.
2. Перейдите в папку проекта (замените путь на свой):
   ```bash
   cd /path/to/bistropastaquiz
   ```
3. Запустите простой сервер:
   ```bash
   python3 -m http.server 8000
   ```
4. Откройте браузер и перейдите по адресу `http://localhost:8000/index.html`.
   Страница автоматически подтянет `styles.css` и `app.js`.

## Самый простой путь: двойной клик (macOS)
1. Откройте папку проекта в Finder и дважды кликните файл **`start_local_server.command`**.
2. Согласитесь на запуск в появившемся окне безопасности (если спросят), Terminal запустится сам.
3. Через пару секунд автоматически откроется браузер с адресом `http://localhost:8000/index.html`.
4. Когда закончите, просто закройте окно Terminal или нажмите **Ctrl+C**, чтобы остановить сервер.

> Скрипт создаёт локальный сервер и открывает страницу. Лог сервера пишется в `/tmp/bistro_pasta_server.log`.

### Как протестировать, если вам 5 лет
1. Дважды кликните файл **`start_local_server.command`**. Если Mac спросит «точно?», нажмите «Да, открыть».
2. Браузер сам откроется. Если вдруг нет — введите в адресной строке `http://localhost:8000/index.html` и нажмите Enter.
3. На первом экране нажимайте большие кнопки и следуйте подсказкам: можете выбрать меню или пройти квиз.
4. Для проверки выберите любое блюдо, дойдите до последнего шага, введите телефон (он уже начинается с +7) и нажмите «Подтвердить заказ». Если появилось «Благодарим за заказ...», значит всё работает.

## Альтернативный способ без сервера
1. В Finder нажмите **Control** и кликните по `index.html`.
2. Выберите **Открыть с помощью → Safari (или другой браузер)**.
3. Если браузер блокирует локальные файлы, используйте вариант со встроенным сервером выше.

## Что внутри
- `index.html` — стартовый экран с двумя сценариями: прямой выбор меню и квиз по настроению.
- `app.js` — логика меню, квиза, выбора филиала, корзины и отправки заказа.
- `styles.css` — оформление карточек, кнопок и экранов.
