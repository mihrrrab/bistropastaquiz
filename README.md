# Bistro Pasta Quiz

Одностраничный навигатор заказа для макароношной «Бистро Паста».

## Настройка отправки в Telegram
1. Создайте бота через `@BotFather` и получите токен.
2. Узнайте `chat_id` (например, написав что-нибудь боту и посмотрев обновления через `getUpdates`).
3. В `index.html` задайте атрибуты тела:
   ```html
   <body data-telegram-bot-token="ВАШ_ТОКЕН" data-telegram-chat-id="ВАШ_CHAT_ID">
   ```
   Альтернативно можно определить глобальные переменные `window.TELEGRAM_BOT_TOKEN` и `window.TELEGRAM_CHAT_ID` до подключения `app.js`.
4. Откройте страницу в браузере, соберите заказ и нажмите «Подтвердить заказ» — бот отправит сообщение о новом заказе.

## Сценарий использования
- Выбор напрямую из меню или через квиз настроения.
- Подборка блюд без изображений меню.
- Выбор филиала и ввод номера телефона в формате `+7XXXXXXXXXX`.
- Автоматическое отправление деталей заказа в Telegram.
